# Synthetic demo script for jury/reviewer

Target 10–12 minutes. Start from a fresh local reset. Say: **all names, responses, transactions and content are synthetic; NUMERIQ is not a diagnostic tool.**

1. **Premise (1 min):** show landing. Explain response evidence and learning support without outcome/clinical claims.
2. **School Admin (2 min):** show aggregates, people/seats, quota, teacher assignment and pending manual upgrade. Admin has no raw answers by default.
3. **Teacher (3 min):** assign a synthetic assessment, explain server-owned/version-pinned scoring, then show evidence threshold, BKT estimate and append-only review. State `NEEDS_REVIEW`.
4. **Supervised child (2 min):** after consent, show resume, hint, one response and one of 12 modules. Return with adult password.
5. **Parent/Home (2 min):** show progress and school-funded Home. Show extra checkout blocked, consent withdrawal and export/delete request.
6. **Evidence (1–2 min):** show green CI: 41 unit, 11 browser, 81 integration and 3 authenticated journeys. End with honest status: `BLOCKED` pending expert, legal/privacy, security and usability approvals.

## Forbidden actions

- No real student, school, parent or payment data.
- Do not mark draft content approved for presentation.
- No live provider key or deployment.
- Do not call BKT/error evidence diagnosis, certainty or clinical risk.
